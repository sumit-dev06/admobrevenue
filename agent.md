## ⚡ Core State Flow & Engine Integration

1. **State Ownership (`src/App.tsx`)**:
   - `adSenseInputs`: Stores website traffic, niche ID, geo tiers, ad units, and overrides.
   - `adMobInputs`: Stores mobile DAU, app genre, formats, OS split, and mediation.
   - `currency`: Active display currency (`USD`, `EUR`, `GBP`, `INR`, `CAD`, `AUD`, `JPY`, `BRL`).
   - `activeMode`: Currently selected calculator mode.
2. **Deterministic Calculation Engines (`src/utils/adCalculations.ts`)**:
   - `calculateAdSenseRevenue(inputs: AdSenseInputs): AdSenseResults`: Computes Page RPM, daily/monthly/annual revenues, ad impressions, clicks, format breakdown, and ad blocker loss.
   - `calculateAdMobRevenue(inputs: AdMobInputs): AdMobResults`: Computes ARPDAU, blended eCPM, daily/monthly/annual revenues, format breakdown, and mediation lift.
   - `calculateReverseGoal(targetMonthly, platform, categoryId, geoTier)`: Computes required pageviews or DAU and 4 milestone stages.
3. **Pure Client-Side Reactivity**:
   - Any slider or input change instantly recalculates results via `useMemo` with 0ms network latency.
